# Optical Edge Vision

## Foundation-model segmentation benchmarks

This repository includes reproducible YOLOv8n, SAM ViT-B, SAM2,
YOLO+SAM2, and reduced SAM3 benchmark artifacts collected on an NVIDIA
Jetson Orin in 15 W power mode.

Model weights and confidential external repositories are excluded.
